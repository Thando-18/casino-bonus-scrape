# Production plan (approximately half a page)

For 200 casinos updated daily, I would run the scraper as a scheduled container on a small cloud VM or managed container service. A low-cost VPS is predictable and easy to monitor; a managed container runner reduces server maintenance. Each source would have its own adapter, polite request rate, timeout, retry/backoff policy, and robots.txt/terms check. The scraper would save the original text, parsed fields, source URL, retrieval timestamp, and extraction confidence so that changes can be audited rather than silently overwritten.

I would use PostgreSQL for structured current offers and history, with a unique key for operator + source + capture date. Automated daily backups would be encrypted, retained for a defined period, and periodically restore-tested. Secrets such as API keys would live in the hosting provider's secret manager or environment configuration, never in Git. The public site could be a static front end on Cloudflare Pages or GitHub Pages, served from a custom domain. DNS would point to the host, and HTTPS would be enabled through the host's managed TLS certificate.

A scheduler such as GitHub Actions cron or a cloud scheduler would trigger the daily job. The pipeline would validate that the expected number of sources were processed and that required fields have valid types. Failed runs, blocked sources, sudden zero-result runs, or unusual offer changes would generate a log entry and an email/Slack alert. I would keep the previous good dataset live if a run fails and add a review queue for ambiguous terms. I would also monitor API usage and rate-limit LLM calls by only reprocessing changed source text.

A rough small-scale monthly budget might be R0–R300 for static hosting, around R100–R250 for a domain averaged monthly, R150–R500 for a small server/database depending on the provider, and R50–R500+ for LLM/API usage depending on token volume. Total planning estimate: roughly R300–R1,500 per month, excluding significant traffic, paid monitoring, and engineering time. I would confirm live provider prices before committing to a budget.
